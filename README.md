**为什么单核主频是命门**

Minecraft 的主线程（main thread）几乎只跑在一个核上，世界生成、实体 AI、红石时序、玩家交互，全挤这一根线。所以业界老炮儿挑机器，从不看"几核几 G"，先看 CPU-Z 单核跑分和最大睿频。Ryzen 9 9950X 这种 Zen5 架构、5.8 GHz 睿频的家伙，单核能跑到 800–900 分；i9-14900K 更夸张，6.0 GHz 睿频，单核 880–900 分。这俩货才是 1.20+ 高版本、模组整合包、群组服的"基本盘"。

而 E5-2666 v3 那种老志强，主频 2.9 GHz、单核 300 出头，跑个 1.12 纯净生存小服还行，你拿它开 1.20 模组服，TPS 直接掉到 15 以下，玩家进服第一件事就是骂街。

**带宽和延迟同样要盯**

带宽决定玩家跑图会不会"区块加载中"，延迟决定你撸怪的时候会不会被怪反杀。国内机房走 BGP 多线，移动联通电信都能 30 ms 内连上；国外机房走 CN2 GIA 或 CMI 9929，丢包少、晚高峰不抽风。这些细节，往往比 CPU 型号更影响"手感"。
